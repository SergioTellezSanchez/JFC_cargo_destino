## Pasos
1. **Entrevista inicial (Fase "Por qué"):** Pregunta el ID de la tarea/ticket (ej. Jira), objetivos concretos y resuelve ambigüedades. Explica el "porqué" de tus preguntas. *Espera respuesta antes de avanzar.*
2. **Alineación Arquitectónica y de Contexto:** Revisa qué componentes serán impactados leyendo `docs/ARCHITECTURE.md` y `docs/TECH_STACK.md`. Identifica explícitamente a cuál de las capas o flujos afecta.
3. **Plan de Trabajo (Desglose):** Crea un checklist de implementación:
   - Sigue un estricto tipado (no `any`), usa componentes modulares y el marco visual "Rich Aesthetics" definido en Momento Nexo.
   - Mapea explícitamente qué tools o skills del proyecto se utilizarán para cada sub-paso.
4. **Validación:** Presenta el plan detallado. Cuando el usuario lo apruebe, avanza con la ejecución estructurada. Requiere Atomic Commits con mensajes semánticos y revisión QA progresiva.
