## Pasos
1. **Entrevista inicial (Fase "Por qué"):** Pregunta el ID de la tarea/ticket (ej. Jira), objetivos concretos y resuelve ambigüedades. *Espera respuesta antes de avanzar.*
2. **Alineación Arquitectónica y de Contexto:** Revisa qué componentes serán impactados usando `docs/ARCHITECTURE.md` y examina el código actual relacionado a la tarea.
3. **Plan de Trabajo (Desglose):** Crea un checklist de implementación:
   - Sigue un estricto tipado (no `any`), usa componentes modulares y el marco visual "Rich Aesthetics" definido en Momento Nexo.
   - Mapea qué tools o skills deben usarse para cada sub-paso.
4. **Aprobación de la Tarea:** Presenta el plan detallado. Cuando el usuario lo apruebe, avanza con la ejecución estructurada (Atomic Commits, revisión QA paulatina).
